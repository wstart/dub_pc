# dub_pc

AdsPower Taskroom：基于 Flask 的远程浏览器任务管理服务。

Flask 任务管理程序。管理员创建独立 AdsPower 环境和随机任务链接；执行者通过网页画面远程操作；点击完成后立即锁定。只有管理员在管理页面点击「重新开放」才能恢复用户权限。当前版本不提供网页内容或正则校验。

## 本地运行

先安装并启动 AdsPower，下载 Chrome 152 内核，开启 Local API 并获取 API Key。程序默认连接 `http://127.0.0.1:50325`，可通过 `ADSPOWER_BASE_URL` 指定本机的其他 API 地址。不要将 Local API 或浏览器调试端口直接暴露到公网。

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
export FLASK_SECRET_KEY='至少32位随机字符串'
export ADMIN_PASSWORD='管理密码'
export ADSPOWER_API_KEY='AdsPower API Key'
.venv/bin/gunicorn --workers 1 --threads 12 --timeout 180 --bind 127.0.0.1:5088 wsgi:app
```

使用已安装的 AdsPower Chrome 152 内核，不需要下载 Playwright 的 Chromium。新任务固定为 Mac 桌面指纹，通过 AdsPower 官方 `random_ua.ua_system_version=["Mac OS X"]` 生成匹配 Chrome 152 的 UA，不手写 UA，也不随机使用移动端系统。已有环境、Cookie 和重新打开逻辑不变。部署前需通过 AdsPower 下载 Chrome 152。Linux 无头服务器无需图形桌面。

Mac 指纹模拟不等于真实 macOS：浏览器仍运行在 Linux 无头服务器上，字体、图形渲染、系统功能和网站判断存在边界，不承诺被网站识别为真实 Mac 用户。需要原生 macOS 行为时应在 Mac 主机运行。语言、时区和 WebGL 等沿用 AdsPower 官方默认匹配，不为每次打开重新生成指纹。

Ubuntu 服务器需要安装中文字体，否则远程浏览器中的中文会显示成方框。安装后刷新字体缓存，并使用新启动的浏览器验证：

```sh
apt-get install -y fonts-noto-cjk
fc-cache -f
```

## 使用

1. 打开管理页，输入管理密码。
2. 输入任务名称、操作起始网址和有效期。需要代理时在「浏览器代理」输入框粘贴整条代理，程序自动识别 HTTP、HTTPS、SOCKS5、地址、端口和认证信息，无需拆开填写；留空则服务器直连。未指定协议时按 HTTP 处理。
3. 创建任务，等待浏览器就绪，再复制任务链接发给对方。
4. 对方点击「开始操作」领取任务。链接绑定第一个领取它的浏览器会话，其他会话不能操作。
5. 对方完成操作后点击「完成任务」。本页立即停止操作。服务端等正在执行的操作结束后记录「已完成」，锁定输入与画面接口，并丢弃尚未执行的输入。完成响应返回后，旧输入不能再执行。不打开校验网页，不运行脚本。
6. 管理员可以打开原浏览器继续操作；用户原链接保持锁定。
7. 管理员在任务卡片点击「重新开放」，恢复原环境、原链接及原领取会话，重新计算原设定时长的有效期。用户重新打开原链接后可以继续；管理员恢复只读观察。其他会话仍不能抢占任务。环境已释放的任务不能重新开放。

清空远程输入框：先点击远程网页中需要清空的输入框，再点击「发送到浏览器」旁的「清空远程输入框」。按钮发送全选和退格，仅操作当前聚焦的远程输入框，不清空下方尚未发送的本地文字。只读或禁用的输入框仍不可修改。用户在完成后不能使用此按钮；管理员在任务结束后的操作模式下可以使用。

远程输入：画面支持左/右/中键、双击、悬停、按住拖动、修饰键点击与滚轮。拖出画面后松开仍释放按键；失焦、取消、断线和任务锁定也会收尾。HTTP 回退时，每个任务页面使用独立输入来源标识，旧窗口的收尾不会释放新窗口的拖拽；该标识不是权限凭证。无法及时收到松开请求时，服务端在最后一次拖拽输入后 15 秒自动释放。Mac 环境下常见全选、复制、剪切、撤销与重做快捷键适配 Command；其他组合保留真实 Control / Meta。

鼠标每 20 毫秒采最新真实位置，每段最多采 100 点，边采边发，不等满 100 点。没有新位置就不重复发送；只保留一条移动待确认和一条最新位置待发送。慢确认时跳过未发中间点，耗尽采样预算后保留最新位置，确认后开始新段。WebSocket 按下和松开不等待移动确认，仍按发送顺序入队，松开带最终坐标；HTTP 回退保持串行。失焦、导航、文字输入及换标签会丢弃旧采样，迟到确认不会补发旧轨迹。

输入连接就绪前，操作按钮保持禁用。HTTP 升级为 WebSocket 时，先收回旧输入队列，确认旧来源的安全释放，再启用新连接。未完成的操作会取消并提示，不自动重发业务输入。未就绪的 WebSocket 重试失败不会取消正在使用的 HTTP 输入。安全释放无法确认时，本页暂停输入并提示刷新，防止后续悬停继续拖动；普通网络重连不会自行解除这个保护。HTTP 物理断网无法即时通知服务端，仍依赖 15 秒无输入租约。服务端释放连续失败时会关闭原浏览器，环境、任务记录和 Cookie 保留，可由管理员重新打开。

中文、Emoji、长文本及粘贴建议使用下方真实文字输入栏。接口拒绝或连接中断时保留尚未接受的草稿。WebSocket 确认只表示操作已通过权限检查并入队，不代表目标网页已执行成功；稍后执行失败仍显示操作错误。首次输入确认超时时，本页立即暂停输入并关闭旧控制连接，清除其余待确认操作，只提示一次；迟到确认或同代状态刷新不会重新开放，也不自动重发原操作。用户需刷新并核对网页实际结果后再操作。屏幕区域是图片，合成 composition / paste 事件测试不证明所有系统和浏览器都能在图片焦点产生原生输入法或剪贴板事件。文本按最终内容插入，不模拟每个字符的按下/松开事件；不支持游戏式持续按键或远程剪贴板回读。

关闭标签：点击标签右侧的「×」。关闭后台标签不会切换当前网页；关闭当前标签会切换至相邻标签。关闭最后一个标签会先创建空白页，不关闭 AdsPower 环境，不清除 Cookie 或登录数据。已关闭的网页不再写入恢复列表。管理员只读观察期间及用户完成任务后，关闭按钮不可操作。

界面提供实时 / 兼容连接状态。任务页地址栏和导航按钮统一为 44 像素高；管理页、任务页和登录页均适配窄屏。前端不加载外部字体或样式库。

任务页使用紧凑工作台布局：顶部直接显示任务名称、状态和完成按钮，完整说明与权限提示收在「任务说明」中。展开说明不会把远程浏览器画面向下推。

网页网络告警按当前标签显示：主页面请求失败显示红色提示；脚本、样式或接口请求失败显示「部分资源加载失败，可能影响页面功能」；图片、字体等失败显示低优先级汇总。告警不判断网站业务功能是否成功，也不改变任务状态。既监听连接错误，也检查 HTTP 4xx/5xx；正常导航导致的请求取消不告警。重复错误合并，每页最多记录 50 项，详情最多显示 8 项；仅显示资源类型、域名与错误码，不返回完整网址、查询参数、请求体或 Cookie。成功加载相同资源、刷新或进入新页面后更新旧告警。系统不增加自动重试，用户自行使用现有刷新按钮。资源监听从连接浏览器后开始，不保证补获连接之前已发生的错误。「实时连接」只表示远程控制连接正常，不代表目标网站加载正常。

默认有效期 60 分钟，最多同时 4 个浏览器会话（包括管理员打开的环境）。没有管理员观察时，任务结束或到期会关闭浏览器，保留 AdsPower 环境与 SQLite 记录。服务器重启会锁定被中断的用户任务并关闭遗留环境；已完成任务的状态不会因管理员会话重启而改变。管理员可以重新开放保留环境的任务，用户不能自行恢复。

管理员打开：任务卡片上的「管理员打开」使用独立的管理员页面，不领取或修改用户会话。用户操作期间，管理员只能观察，服务端拒绝管理员输入。任务完成后，此页面自动转为管理员可操作模式，仍使用原环境，用户原链接保持锁定，直到管理员重新开放。对已经关闭的环境，按钮重新启动原 AdsPower 环境并请求恢复标签页，不新建环境、不改写原任务状态。标签恢复由 AdsPower 决定；若显示空白页，可通过地址栏打开网页，环境内的登录数据沿用。

用户操作期间，管理员页面和管理列表显示「结束观察」。点击后只让管理员退出观察，用户继续操作，浏览器与排队输入不受影响，不改变原领取会话、环境或有效期。任务结束后按钮改为「关闭管理员浏览器」，需要确认才会关闭浏览器，环境、登录数据与任务结果保留。关闭浏览器页面而不点击按钮时，会话在停止心跳 15 分钟后自动结束。管理员会话打开期间不可释放或删除环境，应先结束管理员会话。不要在其他设备同时打开同一个环境。

完成的任务提供「释放环境」操作，管理员确认后删除该任务专属的 AdsPower 环境及登录数据，保留任务结果记录。这可以释放 AdsPower 账号的环境额度。部署验收脚本只会释放它自己创建的两个测试环境。

「删除任务」会永久删除任务记录、结果和剩余的浏览器环境，原任务链接失效。仅允许删除已经结束且浏览器已关闭的任务，需要确认；活动任务先取消。环境删除失败时保留记录，便于重试。

Cookie 管理：仅管理员在任务卡片下点击「查看 Cookie」或「下载 Cookie」时读取已打开环境的完整实时快照，包含其他标签网站、HttpOnly Cookie 和全部浏览器返回字段。关闭的环境先手动点击「管理员打开」，等待连接就绪；查询不会自动启动、关闭浏览器、重新开放任务或清除登录数据。查看区可收起，下载为 JSON 数组，不含任务链接或管理凭据。Cookie 不加入任务列表、用户接口、日志或数据库；请求需管理员会话与 CSRF，响应禁止缓存。列表轮询不会重复读取 Cookie，也不会关闭已展开的查看区。当前 HTTP 传输不加密，Cookie 可能包含登录凭据，请勿外传，正式使用应配置 HTTPS。此功能不导出整个环境或 localStorage，也不承诺导入后所有网站都能恢复登录。

代理认证信息只在创建环境时传给 AdsPower，不保存到任务数据库，也不返回给管理页面或执行者。任务列表只显示代理协议、地址和端口。当前 HTTP 管理页不加密提交的认证信息，正式使用应配置 HTTPS。

旧数据库中的校验字段与历史结果保留以兼容已有记录，但不再读取或执行。新任务的旧校验字段写为空值。`checked_at` 兼容列在新任务中记录用户完成时间；重新开放时清空。

## 服务部署

部署目录 `/opt/adspower-tasks`。服务配置 `deploy/adspower-tasks.service` 使用已有的低权限用户 `adspower`。

`/etc/adspower-tasks.env`：

```dotenv
FLASK_SECRET_KEY=随机字符串
ADMIN_PASSWORD=随机管理密码
TASK_DATABASE=/home/adspower/taskroom/tasks.sqlite3
MAX_TASKS=4
```

密钥文件权限为 600。AdsPower Key 由 systemd 读取现有 `/etc/adspower-headless.env`。Flask 只通过本机访问 AdsPower API；前端不获取 API Key、CDP 地址或校验脚本。不要启用多个 Gunicorn workers，浏览器任务线程由单一进程管理；需要横向扩容时应改为独立持久任务服务。

```sh
systemctl status adspower-tasks
journalctl -u adspower-tasks -n 100
systemctl restart adspower-tasks
```

默认网页端口 5088。对外正式使用时配置域名与 HTTPS 反向代理，并设置 `COOKIE_SECURE=1`。保留 AdsPower API 50325 和浏览器调试端口的本机访问限制。

示例 systemd 配置依赖另行安装的 AdsPower 服务、`adspower` 用户及环境文件；仓库不包含 AdsPower 安装包、账号或 API Key。部署前需按自己的服务器完成这些前置配置，不要直接套用已有服务器的私密文件。

## 仓库与敏感数据

仓库只保存应用源码、部署示例、测试和自有 HTML 测试页面。不提交实际环境文件、密钥、数据库、Cookie、任务链接、部署记录、日志或截图。`reports/` 中的本地验收证据不属于源码发布内容。运行时凭据请通过环境变量或仅服务器可读的配置文件提供。

程序不会自动读取 `.env` 文件。本地运行请先导出环境变量；systemd 部署由单元中的 `EnvironmentFile` 加载服务器配置。

## 测试

```sh
.venv/bin/python -m unittest discover -s tests -v
```

单元测试不需要真实 AdsPower 环境。真实浏览器 UI 回归需单独安装 Playwright 的测试 Chromium：`.venv/bin/python -m playwright install chromium`。该测试浏览器与生产 AdsPower Chrome 内核不同；安装仅用于测试，不替换生产环境。

测试覆盖完成锁定、排队输入清除、重复提交、跨会话权限、到期、重启恢复、管理员鉴权、CSRF、代理参数与认证信息不回显、旧数据库迁移、任务删除与 API 失败时保留记录，以及管理员观察、完成后接管、重新开放、旧操作作废、原环境重开、注销、闲置关闭和故障日志不泄露网址或输入。

服务器真实验收可运行 `.venv/bin/python tests/smoke_proxy.py`。脚本启动仅监听本机的临时 HTTP 认证代理，检查操作页经过代理，完成后没有校验请求，最后删除它自己创建的任务和环境，并验证旧链接返回 404；不会删除其他任务。

清空按钮的真实浏览器验收：`.venv/bin/python -m tests.smoke_clear_input`。脚本检查中文、密码、多行输入框和完成后的操作锁定，最后仅删除它自己创建的临时环境。

Mac 指纹验收：`.venv/bin/python -m tests.smoke_mac_profile`。仅创建一个独立测试环境，核对网页实际收到的 UA、Client Hints、平台和内核版本，检查中文输入、清空、鼠标、实时画面及标签关闭，再正常重开同一环境检查指纹和测试 Cookie 保留；最后删除自己的测试环境，不访问正式任务。

滑块与输入回归：`.venv/bin/python -m tests.smoke_drag_input --output /tmp/taskroom-owned-drag-report --require-remote-drag`。使用自有滑块页面、独立数据库与一个专属 AdsPower 环境，对比直接拖动、直接点击、任务页 WebSocket 和 HTTP 回退，以及两种页面宽度。记录滑块位置、按下/按住移动/松开、传输的操作及截图；同时检查常见鼠标、编辑键、文字发送、取消收尾、管理员观察和完成接管。最后只清理自己的环境。不访问第三方验证码，不验证网站风控，也不修改正式服务。远程拖拽不完整时返回失败；自有输入回归通过不保证第三方验证码通过。

管理员完整回归：`.venv/bin/python -m tests.smoke_admin_browser`。使用独立数据库与一个专属 AdsPower 环境，检查真实画面、观察、接管、重新开放与原环境数据保留，最后仅清理自己的测试环境。前端测试使用独立 Playwright Chromium，需单独安装，不能把测试 UI 放进受控环境。

高延迟回归：`TASKROOM_TEST_LATENCY_MS=400 .venv/bin/python -m tests.smoke_admin_browser`。仅给独立测试连接增加往返延迟，检查新标签、慢页面加载期间的新标签，以及有序输入；不修改服务器网络设置。

生产服务兼容性：`.venv/bin/python -m tests.smoke_websocket_wsgi`。使用独立数据库、模拟环境与 12 线程 Gunicorn，验证实际 WebSocket、完成锁定和连接不可用时的 HTTP 回退。不会操作真实 AdsPower 环境。

输入确认与采样回归：`.venv/bin/python -m tests.smoke_input_timing --output /tmp/taskroom-owned-timing/input-timing.json`。使用临时数据库、模拟环境与真实任务页，检查 100 点 / 20 毫秒采样、浏览器执行阻塞 6.2 秒期间及时接受输入、单条移动待确认，以及完成响应后旧输入作废。`.venv/bin/python -m tests.smoke_input_ack_sampled --output /tmp/taskroom-owned-ack/input-ack.json --only-slow --verify-frame --operation click --hover-count 40 --max-ack-seconds 1` 检查 64 KiB/s 下行的完整大画面、连续悬停和点击确认。两者不访问生产数据库或真实 AdsPower 环境，也不验证第三方验证码。

网络告警与紧凑布局验收：`TASKROOM_UI_SHOTS=/tmp/taskroom-owned-shots .venv/bin/python -m tests.smoke_network_ui`。使用独立数据库和专属 AdsPower 环境，验证主页面/资源错误分级、标签隔离、手动刷新、不自动重试、Cookie 保留、HTTP 回退，以及桌面和手机布局。仅清理脚本自己创建的环境，不操作正式任务。

Cookie 验收：`.venv/bin/python -m tests.smoke_cookies` 使用独立数据库与模拟浏览器验证管理页；服务器上加 `TASKROOM_REAL_COOKIES=1` 使用一个专属 AdsPower 环境，验证跨网站、同名、HttpOnly Cookie、JSON 附件、查看区收起与轮询保留、窄屏布局、关闭时的明确提示、管理员手动重开后的数据保留，以及用户锁定、注销和非管理员拒绝。仅清理自己的测试环境，不操作正式任务。设置 `TASKROOM_COOKIE_SHOTS` 可保存独立测试截图。

浏览器诊断日志记录任务与环境 ID、关闭/崩溃/断线事件、连接状态、异常操作阶段，以及程序主动关闭的时间顺序。不记录完整网址、网页内容、输入、代理密码或 CDP 地址。备用截图偶发超时会保留最后画面并重试，不再关闭任务；真实断线或其他致命异常仍会锁定任务。

输入执行及其收尾达到 1 秒时，记录 `event=input_slow`、任务 ID、角色、操作类型、耗时与待执行命令数；不记录输入内容或页面地址。用于区分接受确认慢与实际浏览器执行慢。

## 当前边界

- 画面、状态和输入共用经过会话、Origin 和 CSRF 验证的 WebSocket，不再为每次操作等待 HTTP 响应或轮询标签。连接不可用时回退到 HTTP 输入、状态轮询和 MJPEG。
- 网页画面使用 CDP 连续采集，最多每秒 10 帧。新客户端将画面按 16 KiB 分片，最多保留 2 个待确认分片（32 KiB），分片间处理输入确认；完整拼回后才显示，完成前不排下一整帧。旧客户端仍兼容整帧协议。大画面的完整显示仍受带宽和往返延迟限制，不承诺网络速度不影响画面。原生采集不可用时回退为短超时截图。连续文字输入及同源连续鼠标移动会合并，点击、松开、文字、导航、修饰键变化与权限边界保持顺序。输入接受和状态读取使用短权限锁，不等待浏览器执行锁。浏览器执行锁仍保留以保障完成响应后旧输入不能执行；极慢的单次浏览器调用仍可能拖延实际操作、物理松开或完成响应。
- 网址导航、返回和刷新不等待页面加载；复用页面调试连接，避免慢网页在释放连接或切换画面时阻塞新标签。
- 默认 12 个服务线程中，最多 8 个用于实时连接或画面流，其余保留给管理。完成、到期、退出观察或管理员注销都会收回对应连接；重新开放后旧连接不能继续访问。
- 支持鼠标点击、双击、悬停、通用拖拽、修饰键、键盘、滚动、中文文字输入、网址导航、标签切换、新建及关闭标签页。
- 暂不支持多点触控手势、持续按键、系统文件选择、文件上传下载、音视频与浏览器扩展界面。不承诺第三方滑块验证码通过。
- AdsPower 账号的环境额度与浏览器内核决定可创建的实际数量。
